# Survey Workflow Automation

A portfolio of Python tools and Maptek PointStudio workflows
developed to simplify repetitive mine survey tasks.

## About

My work combines mine surveying, LiDAR data processing,
surface modelling, volume calculations, and workflow automation.

These projects focus on reducing manual steps and improving
consistency in daily survey data preparation and processing.

## Portfolio Scope

### Maptek PointStudio Workflows
- Create surfaces from multiple boundaries.
- Create surfaces from pointclouds in separate containers.
- Copy pointclouds to multiple destination containers.
- Calculate volumes between matching Top and Base surfaces.

### Python Tools
- Format ICP/GS coordinates for import into PointStudio.
- Merge daily RTK survey files into one import-ready CSV.

### Regex
- Clean copied object names in bulk.
